## Output contract

Return only one JSON object, with no text around it, with these fields:

- `kind` — "latex" when the line is a formula or math, "text" when it is words.
- `text` — the line as it is written: LaTeX for "latex", plain text for "text".
- `sympy` — for "latex", the same expression in SymPy syntax when it parses as math; otherwise null.
- `confidence` — how sure you are of the reading, from 0 to 1.
- `crossed_out` — true when the line is struck through.
